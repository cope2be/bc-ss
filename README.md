# Battle Cats Seed Seeker
A simple [seed seeker](https://cope2be.github.io/bc-ss/) for The Battle Cats with no queues

## How is it queueless?
This seed seeker is queueless because it utilities WebAssembly to calculate the seed directly in your browser

This means you don't have to wait in a queue, though the calculation time varies depending on the device's hardware

But it is usually very quick due to the backend being written in C, a high performance language
